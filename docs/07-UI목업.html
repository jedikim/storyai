복선 보드

복선은 (설정 F → 트리거 T → 회수 P) 3항으로 저장됩니다. 트리거가 없으면 “아직 안 터진 복선”과 “근거 없이 터진 회수”를 구분할 수 없습니다.

이중 시간축

가로축은 독자에게 드러난 순서(discourse), 세로 위치는 작중 실제 시간(story)입니다. 두 축이 어긋난 구간이 회상·플래시백이고, 그 어긋남 자체가 데이터입니다.

검수 큐
